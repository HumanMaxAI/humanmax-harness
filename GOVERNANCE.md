# Governance

The company GitHub organisation owns this repository, release identities, and package namespaces.

Until those names are reserved, treat current package names as intent, not a published claim.

Minimum future controls:

- At least two organisation owners
- Protected `main` and required review
- Signed / tagged releases
- CODEOWNERS for contracts, rules, packs, and release workflows
- Public changelog and deprecation policy
- Security contact in `SECURITY.md`
