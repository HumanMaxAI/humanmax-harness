## Release conditions

1. Run the release PR's required CI checks. They must pass.
2. Integrate under the repository review policy. The agent must not approve its own diff.
3. Run main CI with the existing `prod` GitHub OIDC Trusted Publisher. Workspace, generated-project, both CodeQL jobs, and publish must succeed.
4. Confirm that public npm contains all eight 0.2.0 versions with Node >=26.
5. Install public entry packages into a temporary directory. Generate a project and run install/ci, build, typecheck, tests, and project-pinned CLI checks.
6. Record the main commit and publication evidence. Tag only after verification.

## Limits and recovery

Node 22 users must remain on 0.1.x. Full upgrade apply remains outside Preview. Passing these checks does not prove production enforcement. Publication is immutable; do not reuse or overwrite an existing version. If publication stops after some packages succeed, retain those versions and retry only the remaining packages through the corrected CI path.
